Meu Portfólio Web

Este portfólio foi desenvolvido utilizando HTML e CSS com o objetivo de apresentar meus projetos e habilidades de forma clara e visualmente atraente. A estrutura do site foi cuidadosamente planejada para garantir uma navegação intuitiva, proporcionando uma experiência fluida e responsiva para todos os dispositivos.

Habilidades:

HTML: Utilizo HTML5 para estruturar páginas web de forma eficiente, com foco em semântica e acessibilidade. Minha experiência inclui a criação de layouts otimizados e compatíveis com diferentes navegadores.

CSS: Tenho sólidos conhecimentos em CSS3, permitindo a criação de designs responsivos, animações sutis e uma estilização personalizada para cada projeto. Utilizo boas práticas para garantir que o código seja organizado e fácil de manter.
